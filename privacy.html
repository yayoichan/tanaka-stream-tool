Privacy Policy

Last updated: November 7, 2026

Tanaka Stream Tool ("the tool") is a personal tool used only by its developer to run the AI VTuber channel 田中・エージェンティック・あのんちゃん. It is not offered to other users.

What the tool accesses

With the channel owner's permission given through Google OAuth, the tool accesses the owner's own YouTube channel through the YouTube API Services. It:

  • reads the owner's own live broadcasts and their live chat messages (the viewer's display name and message text);
  • updates the title and thumbnail of the owner's own live broadcasts;
  • uploads short videos to the owner's own channel.

How the data is used

  • Live chat messages are used only to let the virtual character reply during the stream, and to make the stream log and highlight clips.
  • To generate the character's replies, chat text is sent to the AI model provider (Anthropic). It is not used for any other purpose.
  • Data is not sold, and is not shared with any other third party.

Storage and deletion

  • Data is stored only on the developer's own PC.
  • The developer can delete the stored data at any time.
  • Access to the YouTube account can be revoked at any time from Google Account permissions.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
