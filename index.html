Tanaka Stream Tool

A personal streaming tool for the AI VTuber channel 田中・エージェンティック・あのんちゃん.

What it does

Tanaka is a virtual character run by an AI. The developer streams casual talk shows with Tanaka on Twitch and YouTube from a personal PC. This tool is used only by the developer to run the channel.

  • Finds the channel's own live broadcast on YouTube and sets its title and thumbnail.
  • Reads the live chat of the channel's own broadcast, so the character can reply during the stream.
  • After a stream, makes short vertical highlight clips from the recording. The developer reviews each clip, decides its title, and uploads the chosen clips to the channel as YouTube Shorts.

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
